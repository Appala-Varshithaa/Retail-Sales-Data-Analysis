# Sales Data Analysis Using Python

## 📌 Project Overview

This project analyzes sales data using Python to identify important business insights such as total revenue, top-selling products, revenue by region, revenue by category, and monthly revenue trends.

The project uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data cleaning, analysis, and visualization.

## 🎯 Objectives

- Analyze overall sales performance
- Calculate total revenue
- Identify top-selling products
- Analyze revenue by region
- Analyze revenue by product category
- Analyze monthly revenue
- Understand revenue distribution
- Identify potential outliers in order revenue

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## 📂 Dataset

The project uses a sales dataset containing 5,000 records.

Dataset file:

`sales_data_5000.csv`

Important columns used in the analysis include:

- Order_Date
- Product
- Quantity
- Price
- Region
- Category

## 🔄 Data Cleaning

The following data preprocessing steps were performed:

1. Loaded the dataset using Pandas.
2. Checked the structure and information of the dataset.
3. Checked for missing values.
4. Removed rows containing missing values.
5. Converted `Order_Date` into datetime format.
6. Created Month and Year columns.
7. Created a Revenue column.

Revenue was calculated as:

`Revenue = Quantity × Price`

## 📊 Analysis Performed

### 1. Total Revenue

Calculated the total revenue generated from all orders.

### 2. Top-Selling Products

Identified the top 10 products based on total quantity sold.

### 3. Revenue by Region

Analyzed total revenue generated by each region.

### 4. Revenue by Category

Compared revenue generated across different product categories.

### 5. Monthly Revenue

Analyzed revenue across different months.
